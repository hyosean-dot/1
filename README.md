# 마음 톡톡! 언어 배우는 AI 친구

언어를 말로 연습하는 웹앱 프로토타입입니다. Google Gemini API 무료 등급 모델(기본 `gemini-2.5-flash`, 프로젝트에서 사용 가능한 모델로 변경 가능)을 서버에서 호출합니다. 음성 인식과 음성 출력은 브라우저의 Speech Recognition / Speech Synthesis를 이용하며, 선택적 얼굴 추적은 브라우저 내 MediaPipe로 수행합니다.

## 공개 URL 배포

Render에서 이 저장소를 새 Web Service로 연결하면 `render.yaml` 설정을 읽어 배포할 수 있습니다. Render 대시보드에서 비밀 환경변수 `GEMINI_API_KEY`에 Google AI Studio API 키를 입력하고 배포하세요. 배포가 성공하면 서비스가 HTTPS URL을 제공합니다. 그 URL만으로 접속할 수 있지만, 무료 호스팅은 유휴 상태 이후 잠자기/첫 요청 지연이 있을 수 있으며 Google 무료 쿼터도 무제한이 아닙니다. 브라우저 음성 인식은 브라우저/기기별 지원 여부가 다르므로 글 입력도 제공합니다.

로컬 실행은 Node.js 20 이상에서 `GEMINI_API_KEY`를 서버 환경변수로 설정한 뒤 `npm start`를 실행하면 됩니다. `.env.example`은 설정 예시이며 `.env`는 Git에 저장하지 마세요. API 키를 HTML/JavaScript 또는 공개 저장소에 넣지 마세요.

## 저장과 개인정보에 대한 정확한 설명

이 앱은 대화·오디오·영상·사용자 계정을 자체 DB나 파일에 저장하지 않으며, 대화는 페이지를 닫거나 새로고침하면 사라집니다. 카메라 영상은 얼굴 랜드마크 계산을 위해 브라우저에서만 처리하고 앱 서버나 Gemini에 전송하지 않습니다. **하지만 음성 인식은 브라우저 업체의 서비스에 음성을 보낼 수 있고, 인식된 텍스트는 답변 생성을 위해 Google Gemini API로 전송됩니다.** 따라서 “개인정보가 절대 노출되지 않는다”거나 “Google에도 전혀 전달되지 않는다”고 보장할 수는 없습니다. Google 무료 등급의 데이터 취급 조건, 호스팅/브라우저 로그를 검토하고 공개 전 보호자 동의·개인정보 고지를 마련해야 합니다. 어린이에게 이름·주소·학교·전화번호 등 개인정보를 말하거나 입력하지 않도록 안내하세요.

서버는 음성 원본을 받거나 대화 내용을 디스크에 기록하지 않습니다. 기본 HTTP 서버 로그에도 사용자 대화 본문을 기록하지 않도록 작성했지만, 호스팅 플랫폼/Google/브라우저의 자체 처리와 로그 정책은 앱이 통제하지 못합니다. 운영 배포에는 남용 방지 및 사용자별 한도 설정이 필요합니다.

## 모음 입 모양

아바타는 답변 텍스트를 언어별 브라우저 TTS로 읽고, 한국어는 한글 음절에서 모음을 분해해, 영어 등은 철자 모음을 사용해 `a/e/i/o/u` 입 모양을 순서대로 애니메이션합니다. 이는 **모음 단위의 근사 애니메이션**입니다. 일반 브라우저 TTS는 정확한 음소 타임스탬프를 제공하지 않고 철자와 발음이 일대일이 아니므로, 모든 언어에서 실제 발화의 음소와 정확히 동기화되는 정밀 립싱크라고 보장할 수 없습니다. 정확한 음소별 동기화에는 음소 타임스탬프를 내는 TTS/정렬 서비스가 필요합니다.

기본 언어 선택: 영어, 한국어, 일본어, 스페인어, 프랑스어. 얼굴 추적/음성 인식 기능은 HTTPS와 브라우저 권한이 필요합니다.
