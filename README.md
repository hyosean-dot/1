# 마음 톡톡! 언어 배우는 AI 친구

어린이가 웹 주소로 접속해 언어 연습을 해보는 프로토타입입니다. Google Gemini API 텍스트 모델(기본 `gemini-2.5-flash`)이 짧은 답변을 만들고, 음성 인식·음성 출력은 브라우저의 Speech Recognition / Speech Synthesis 기능을 사용합니다. 지원 여부와 음성 처리 방식은 브라우저·기기에 따라 다릅니다. 선택형 얼굴 추적은 MediaPipe로 브라우저 안에서 수행합니다.

## 공개 URL 배포

저장소를 Render Web Service로 연결하면 `render.yaml` 설정을 이용할 수 있습니다. 배포 설정에서 `GEMINI_API_KEY`를 서버의 비밀 환경변수로 등록하고, AI Studio 프로젝트에서 사용할 수 있는 모델 ID인지 확인하세요. 배포가 성공하면 호스팅 플랫폼이 HTTPS 주소를 제공합니다. 사용자는 그 URL로 접속할 수 있습니다. 이 문서는 배포를 설정할 뿐이며, 실제 배포·URL 생성은 호스팅 계정 연결과 API 키 등록 후 플랫폼에서 완료해야 합니다. 무료 호스팅이나 Gemini 무료 쿼터는 무제한·항상 가동을 보장하지 않습니다.

로컬은 Node.js 20 이상에서 서버 환경변수 `GEMINI_API_KEY`를 설정하고 `npm start`를 실행합니다. API 키를 HTML/JavaScript 또는 저장소에 넣지 마세요. `.env`는 Git에서 제외됩니다.

## 저장·전송에 대한 정확한 안내

이 앱 코드는 대화 이력, 음성, 영상, 계정을 자체 DB·파일·브라우저 저장소에 기록하지 않습니다. 대화는 페이지에 표시되는 동안 메모리에만 존재하며 새로고침/닫기 후 사라집니다. 서버는 요청 내용을 앱 로그에 쓰지 않으며 IP 주소는 메모리 기반 요청 제한을 위해 잠시 사용될 수 있습니다.

그렇다고 개인정보가 절대로 외부에 노출되지 않는다고 보장할 수는 없습니다. 텍스트 대화는 답변 생성을 위해 Google Gemini API로 전송됩니다. 브라우저 음성 인식은 브라우저/기기 제공업체의 서비스에서 처리될 수 있고, 그 처리 방식은 앱이 통제하지 않습니다. 호스팅·Google·브라우저 서비스의 정책, 네트워크/서비스 로그와 보관 조건을 확인하세요. 공개 전 보호자와 함께 개인정보 처리 안내 및 필요한 동의 절차를 마련하세요. 이름, 주소, 학교, 전화번호 등 개인정보를 말하거나 입력하지 않도록 안내합니다. 앱의 개인정보 패턴 검사는 일부 입력을 걸러내는 보조 기능일 뿐 완벽한 탐지·보호가 아닙니다.

카메라 영상은 사용자가 추적을 켜고 브라우저 권한을 허용한 경우에만 얼굴 랜드마크 계산에 사용됩니다. 앱 코드는 영상 프레임을 서버나 Gemini에 전송하지 않습니다. 얼굴 추적 모델과 라이브러리는 외부 CDN에서 내려받습니다.

## 모음 입모양 및 기능 한계

AI 답변 텍스트는 브라우저 TTS로 읽으며, 한글 음절에서 모음을 분해하고 라틴 문자 모음도 근사적으로 `a/e/i/o/u` 입모양에 대응시켜 순서대로 애니메이션합니다. 브라우저 TTS의 실제 음소 타이밍을 제공받는 방식이 아니므로 실제 발음과 정확히 동기화되는 음소 립싱크가 아닙니다. 음성 인식은 지원하지 않는 브라우저에서 동작하지 않을 수 있으며 텍스트 입력 대안을 제공합니다.

앱은 보호자 확인 체크 없이는 텍스트 전송, 마이크 음성 인식, 카메라 추적을 시작하지 않습니다. 이 확인은 법률상 보호자 동의 절차를 대체하지 않습니다. 어린이는 보호자와 함께 사용해야 합니다.
